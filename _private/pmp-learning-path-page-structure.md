# PMP Learning Path Page Structure

> 用途：作为站内“PMP 学习路径”页面的内容结构说明。核心教材以本地资料包中的 `PMBOK® Guide 双语对照.pdf` 为主，其他资料作为练习、冲刺和错题复盘补充。

## 1. 页面定位

页面目标不是简单罗列资料，而是给备考者一条可以执行的路径：

- 先读 PMBOK 的标准、价值交付、原则和生命周期，建立项目管理判断框架。
- 再进入 PMBOK 指南第八版的绩效领域、个体化方案、输入输出、工具技术。
- 每个阶段都配套对应练习，避免只看书不做题。
- 后半段以模考、错题归因、敏捷专项和考前清单为主。

推荐主路径：45 天。

适用人群：

- 已经报名或计划报名 PMP 的考生。
- 有项目经验，但知识体系不完整的人。
- 需要把 PMBOK 中文/英文术语、场景题判断和模考节奏串起来的人。

重要说明：

- 页面公开展示时，只展示学习路径、章节摘要、复习任务和站内自有题库入口。
- `PMBOK® Guide 双语对照.pdf` 及资料包中的 PDF / DOCX / RAR 文件仅作为内部备课来源或用户自有资料引用，不建议在网页公开提供全文下载，避免版权和广告审核风险。

## 4. 45 天学习路径

### 第 1 阶段：建立考试地图和基础概念

时间：第 1-5 天

对应章节：

- 项目管理标准：第1节 引言
- PMBOK 指南第八版：第1节 引言

对应章节的知识点：

- 项目、项目集、项目组合、运营的区别。
- 项目治理与组织治理的关系。
- 项目启动、项目环境、组织结构。
- PMBOK 标准与 PMBOK 指南的关系。
- PMP 考试不是背定义，而是判断项目经理在当前场景下的下一步动作。

关键知识重点：

- 先把“项目经理能做什么、不能做什么”讲清楚。
- 重点区分 sponsor、project manager、project team、customer、product owner、PMO。
- 看到题目先判断场景，而不是直接找关键词套答案。
- PMP 场景题常见顺序：先分析、先沟通、先查计划、先评估影响，再行动。

相关习题：

- `PMP-分章习题.rar`：基础概念章节题。
- `PMP知识点整理300条.pdf`：每天读 30-50 条，建立术语熟悉度。
- 站内 PMP 练习题：优先做基础、角色、治理类题目。

页面展示建议：

- 模块标题：`Days 1-5: Build the PMP map`
- 卡片字段：章节、学习目标、今日阅读、今日练习、错题归因。

### 第 2 阶段：价值交付、原则和生命周期

时间：第 6-12 天

对应章节：

- 项目管理标准：第2节 价值交付系统
- 项目管理标准：第3节 项目管理原则
- 项目管理标准：第4节 项目生命周期

对应章节的知识点：

- 价值创造、价值交付组件、项目成功评估。
- 项目环境、企业环境因素、组织过程资产。
- 项目管理原则：系统思维、价值导向、质量、领导力、可持续性、赋能文化等。
- 预测型、自适应、混合型生命周期。
- 生命周期选择的影响因素：需求稳定性、交付频率、风险、组织成熟度。

关键知识重点：

- “价值”是 PMP 情景题的核心，不是只看进度或成本。
- 生命周期不是标签题，要从需求变化程度、团队协作方式、交付节奏判断。
- 预测型题常出现计划、基准、变更控制。
- 敏捷题常出现 backlog、迭代、回顾、团队自组织、产品负责人。
- 混合题通常是硬件/合规/总体计划偏预测，软件/需求细化偏敏捷。

相关习题：

- `PMP-分章习题.rar`：生命周期、组织环境、价值交付相关题。
- `pmp敏捷核心考题50题_加水印.pdf`：开始做敏捷识别题。
- `PMP 做题技巧36计_加水印.pdf`：结合“下一步”题型训练。
- 站内 PMP 练习题：按 agile / hybrid / predictive 标签筛选。

页面展示建议：

- 模块标题：`Days 6-12: Learn how PMP questions describe the project environment`
- 增加一个三列对照表：`Predictive signals / Agile signals / Hybrid signals`。

### 第 3 阶段：绩效领域主干一：治理、范围、时间、财务

时间：第 13-20 天

对应章节：

- PMBOK 指南第八版：2.1 治理绩效领域
- 2.2 范围与性能领域
- 2.3 时间绩效领域
- 2.4 财务绩效领域

对应章节的知识点：

- 治理模式、项目价值创造、治理评估指标。
- 范围定义、需求、WBS、验收标准、范围基准。
- 进度计划、活动排序、关键路径、进度基准。
- 成本估算、预算、成本基准、绩效测量。

关键知识重点：

- 范围题不要直接同意新增需求，应先评估影响并走变更流程。
- 进度题不只看赶工和快速跟进，还要判断风险和成本影响。
- 成本题要会理解预算、估算、EVM 指标的含义，但不必只靠公式记忆。
- 治理题通常考“谁有权决策、项目经理应该先找什么依据”。

相关习题：

- `PMP-分章习题.rar`：范围、进度、成本、治理题。
- `PMP考试100题+项目管理 常考知识点汇总.pdf`：做范围/进度/成本常考题。
- `PMP知识点整理300条.pdf`：补齐 WBS、baseline、change request、EVM 等术语。
- 站内 PMP 题库：优先做 Process 类、change control 类、planning 类题目。

页面展示建议：

- 模块标题：`Days 13-20: Turn plans, baselines, and changes into decisions`
- 每个绩效领域卡片后面显示：阅读章节、关键文件、常见错误、练习入口。

### 第 4 阶段：绩效领域主干二：干系人、资源、风险

时间：第 21-27 天

对应章节：

- 2.5 利益相关者绩效领域
- 2.6 资源绩效领域
- 2.7 风险绩效领域

对应章节的知识点：

- 干系人识别、分析、参与、沟通。
- 团队资源、实物资源、责任分配、冲突处理。
- 风险识别、定性/定量分析、风险应对、问题升级。
- 风险与问题的区别。
- 沟通管理计划、干系人参与计划、风险登记册、问题日志。

关键知识重点：

- 干系人不支持时，通常先分析原因、沟通、更新参与策略，而不是直接升级。
- 团队冲突题先促进沟通和协作，不要马上换人或处罚。
- 风险是未来不确定事件，问题是已经发生的事件。
- 风险题要先看风险登记册、风险应对计划、风险责任人。
- 升级不是不能做，但通常不是第一步。

相关习题：

- `PMP-分章习题.rar`：干系人、沟通、资源、风险题。
- `PMP考试过关口诀_加水印.pdf`：用于记忆“先沟通、先评估、先查计划”。
- `PMP 做题技巧36计_加水印.pdf`：用于情景题下一步训练。
- 站内 PMP 题库：重点刷 stakeholder、communication、risk、team 场景题。

页面展示建议：

- 模块标题：`Days 21-27: Practice people, stakeholder, and risk judgment`
- 增加“容易选错的动作”提示：直接升级、直接换人、直接批准、直接拒绝。

### 第 5 阶段：个体化方案、输入输出、工具技术

时间：第 28-34 天

对应章节：

- 第3节 个体化方案
- 第4节 输入与输出
- 第5节 工具与技术

对应章节的知识点：

- Tailoring 的原因、流程和适用场景。
- 生命周期与开发方法选择。
- 项目管理计划、子计划、登记册、日志、报告、基准、交付物。
- 工具技术：会议、专家判断、数据分析、决策、估算、图表、审计、回顾。

关键知识重点：

- PMP 不要求死背每个输入输出，但要知道“题目问下一步时该查什么文件”。
- 变更题优先关联：变更请求、变更日志、变更控制委员会、影响评估、基准。
- 风险题优先关联：风险登记册、风险报告、风险应对计划。
- 干系人题优先关联：干系人登记册、干系人参与计划、沟通管理计划。
- 敏捷题优先关联：product backlog、sprint backlog、review、retrospective、definition of done。

相关习题：

- `PMP知识点整理300条.pdf`：每天整理 20 个输入输出/工具技术关键词。
- `核心考点91页纸（三色笔记）.pdf`：快速补弱项。
- `PMP-分章习题.rar`：输入输出、工具技术相关题。
- 站内 PMP 题库：做 mixed scenario drill，不按章节提示做题。

页面展示建议：

- 模块标题：`Days 28-34: Know which plan, register, or artifact to use`
- 做一个“场景 → 先查文件 → 再采取行动”的表格。

### 第 6 阶段：敏捷与混合专项

时间：第 35-38 天

对应章节：

- 项目生命周期中的自适应与混合方法。
- 工具技术中与敏捷、协作、迭代、回顾相关内容。
- PMBOK 中团队、干系人、风险、价值交付相关章节交叉复习。

对应章节的知识点：

- Scrum Master、Product Owner、Development Team 的职责。
- Daily Scrum、Sprint Planning、Sprint Review、Retrospective。
- Product backlog、Sprint backlog、优先级、价值交付。
- Kanban、WIP、可视化工作流。
- 敏捷变更如何进入 backlog。

关键知识重点：

- Product Owner 决定价值和优先级，不是项目经理替 PO 排优先级。
- Scrum Master 是仆人式领导，重点是移除障碍、促进协作。
- 团队自组织不等于没人管理，而是不由项目经理直接分派每个任务。
- 迭代评审看产品增量和反馈，回顾会议改进团队过程。
- 敏捷题遇到变更，通常不是走传统 CCB，而是进入 backlog 并重新排序。

相关习题：

- `pmp敏捷核心考题50题_加水印.pdf`
- `PMP考前背记知识点——敏捷_加水印.pdf`
- `2026年新版PMP敏捷内部密训压题卷_加水印.pdf`
- 站内 PMP 题库：敏捷、混合、团队协作类题目。

页面展示建议：

- 模块标题：`Days 35-38: Separate agile judgment from predictive change control`
- 增加 Scrum / Kanban / Hybrid 判断表。

### 第 7 阶段：第一次完整模考和错题归因

时间：第 39-41 天

对应章节：

- 不再按章节读书，以全范围模考为主。
- 错题回流到前六个阶段对应模块。

对应章节的知识点：

- People / Process / Business Environment 的综合判断。
- 当前版本与新版权重变化需要单独提醒，但不应干扰当次复习路径。
- 180 题考试节奏：平均约 1 分钟 20 秒一题。

关键知识重点：

- 错题不要只记答案，要分类：
  - 概念不懂。
  - 题干关键词没抓住。
  - 敏捷和预测型混淆。
  - 变更、风险、干系人、沟通流程混淆。
  - 英文术语误解。
- 模考后至少用同等时间复盘。
- 如果连续错同类题，应回到对应章节重读，而不是继续刷新题。

相关习题：

- `中英双语PMP200 道全真模拟题.pdf`

- `2511-模考+解析【快速过一遍题和解析】.pdf`
- `2026年PMP学习打卡表.xlsx`

页面展示建议：

- 模块标题：`Days 39-41: Take one full mock and rebuild weak areas`
- 页面提供错题复盘模板：错因、对应章节、正确判断顺序、下次提醒。

### 第 8 阶段：冲刺、背记和第二次模考

时间：第 42-45 天

对应章节：

- PMBOK 主教材只回看标记章节。
- 重点看工具技术、输入输出、风险/变更/干系人/敏捷错题。

对应章节的知识点：

- 项目经理下一步判断。
- 变更控制流程。
- 风险与问题处理。
- 干系人沟通。
- 敏捷角色和会议。
- 采购和合同基础。

关键知识重点：

- 考前不再大面积读新材料。
- 每天只做三件事：回看错题、做一组混合题、复述判断规则。
- 对模糊题，用“先分析、先沟通、先查计划、先评估影响、避免越权”来筛选。
- 考前最后一天重点调整节奏，不建议再做大量新题。
