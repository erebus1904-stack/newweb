Practice path

Use one knowledge base, but follow different exam paths.

PMP and CAPM overlap in project management vocabulary, delivery approaches, stakeholder work, risk, scope, schedule, cost, quality, agile, and business analysis. The practice path changes because CAPM tests foundation and recognition, while PMP expects scenario judgment, leadership tradeoffs, and exam-time decision discipline.

Shared project management foundation

Use the same core ideas for both tracks: lifecycle, constraints, stakeholders, risks, issues, change control, agile roles, predictive planning, and value delivery. This is the base layer behind both question banks.

CAPM path

Choose CAPM when you need entry-level reinforcement. Work by domain, read each explanation immediately, and connect missed terms to CAPM guides before adding more questions.

PMP path

Choose PMP when you need scenario practice. Work by chapter or domain, then use the 180-question mock exam only after you can explain why each missed answer was wrong.

Next review loop

After every session, sort misses by cause: weak concept, wrong role, missed keyword, skipped impact analysis, poor agile signal, or time pressure. Then return to the matching guide and practice path.
